# Supermarket Sales Analysis 📊

## About the Project
This project analyzes supermarket sales data using Python to understand sales performance and customer behavior.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Performed
- Data cleaning
- Sales by product category
- City-wise sales analysis
- Payment method analysis
- Monthly sales trends
- Customer rating analysis
- Quantity sold analysis

## Key Findings
- Naypyitaw had the highest sales among the three cities.
- January had the highest monthly sales.
- February sales decreased.
- March sales recovered compared to February.

## Project Purpose
To practice Python data analysis and extract useful business insights from sales data.
